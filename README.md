# 🚀 Interactive Personal Data Collector

A fundamental Python booster project designed to demonstrate core programming concepts including user input, data type conversion, string formatting, and memory management basics.

## 📚 Concepts Covered

This project is perfect for beginners looking to understand:

* **Variables & Data Types:** Working with `str`, `int`, and `float`.
* **Standard I/O:** Using `input()` to get data and `print()` to display it.
* **String Formatting:** Using Python f-strings (`f"..."`) for clean and readable output.
* **Memory Introspection:** Understanding how Python stores variables in memory using `id()`.
* **Basic Mathematics:** Performing simple calculations with user-provided data.

## ✨ Features

* **Interactive Data Collection:** Prompts users to input various types of information (name, age, height, favorite number).
* **Type Casting:** Demonstrates converting raw string inputs into usable mathematical data types.
* **Under the Hood:** Utilizes Python's built-in `type()` and `id()` functions to display the specific data class and the exact memory address where each variable is stored.
* **Dynamic Calculation:** Automatically computes the user's approximate birth year using basic arithmetic based on the current year.

## 🛠️ Prerequisites

* **Python 3.x** installed on your system.
* A basic text editor or IDE (like VS Code, PyCharm, or Notepad).

## 💻 How to Run

1. Save the provided Python code into a file named `data_collector.py`.
2. Open your terminal or command prompt.
3. Navigate to the folder where you saved the file.
4. Execute the script using the following command:
```bash
python data_collector.py

```


5. Follow the on-screen prompts to enter your details and see the results!
